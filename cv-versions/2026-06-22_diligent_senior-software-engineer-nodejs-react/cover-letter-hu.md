# Motivációs levél — Senior Software Engineer (NodeJS, React) @ Diligent

Kedves Felvételi Csoport,

A Senior Software Engineer pozícióra jelentkezem a Diligent-nél. Az a küldetésetek, hogy a vezetőket technológiával, betekintéssel és kapcsolatokkal felruházzátok a nagyobb hatású kormányzás érdekében, közel áll ahhoz, amiben hiszek: megbízható, jól tesztelt szoftver építése, amely valós üzleti igényeket szolgál ki.

Az elmúlt öt évben React, TypeScript és Node.js technológiákkal építettem produktív webes alkalmazásokat. Az Aegex Technologies-nél, ahol jelenleg Frontend Tech Leadként dolgozom, legacy vállalati rendszereket modernizáltam teljes újraírással és modern stackekre való migrációval — közvetlenül releváns tapasztalat a Diligent GRC platformjainak modernizálásához.

Technikai hátterem jól illeszkedik az elvárásaitokhoz. Van tapasztalatom MySQL adatbázisokkal és REST API-kkal, valamint Express és Node.js backend szolgáltatásokkal. CI pipeline-okat vezettem be automatizált minőségi kapukkal és kódszabványokat hoztam létre csapatokon át.

Ami a Diligent-et vonzóvá teszi számomra, az a technikai mélység és a valós hatás kombinációja. Felelősséget vállalok a munkámért, mentorálom a csapattagokat és folyamatosan okosabb megoldásokat keresek. Automatizált tesztelési stratégiákat vezettem be (Jest, Vitest, Playwright) a semmiből, és hiszek a folyamatos folyamatfejlesztésben — legyen szó jobb eszközökről, finomított munkafolyamatokról vagy tudásmegosztásról.

Van tapasztalatom Azure Static Web Apps-szel és React alkalmazások CI/CD pipeline-okkal GitHub Actions segítségével. Az eseményvezérelt architektúrát WebSocket-alapú valós idejű rendszereimből ismerem.

Örömmel beszélnék arról, hogyan járulhat hozzá tapasztalatom a legacy rendszerek modernizálásában, SQL és REST API-val végzett munkában és jól tesztelt megoldások építésében a Diligent zászlóshajó termékeihez.

Üdvözlettel,
