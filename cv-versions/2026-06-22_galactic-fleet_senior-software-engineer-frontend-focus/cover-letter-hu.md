# Motivációs levél — Senior Software Engineer / Frontend focus @ Galactic Fleet

Kedves Felvételi Csoport,

Frontend fejlesztő vagyok 5+ év tapasztalattal interaktív, produktív webes alkalmazások fejlesztésében — és mindig is szenvedélyesen érdekelt a játékfejlesztés. Amikor megláttam ezt a pozíciót a Galactic Fleet-nél, úgy éreztem, mint a tökéletes összecsengés a szakmai készségeim és a személyes érdeklődéseim között.

Szakmailag React, TypeScript és Node.js technológiákkal dolgozom. Az Aegex Technologies-nél valós idejű, adatvezérelt felületeket fejlesztek, beleértve WebSocket-alapú élő rendszereket, amelyek nagy frekvenciájú adatfolyamokat kezelnek — közvetlenül releváns tapasztalat interaktív, vezérelt játékélményekhez. Cross-platform UI megoldásokat is fejlesztettem, amelyek eszközök széles skáláján működnek — ez illeszkedik a többplatformos smart TV és hangszóró céljaitokhoz.

Ami a leginkább izgat, az az, hogy a játékfejlesztés nem csak szakmai érdeklődés — aktívan csinálom. Építettem egy teljes 2.5D RPG játékot (cv-game) Canvas API-val, egyéni játékmotorral, entitáskezeléssel, csempés alapú térképrendezéssel, ütközésdetekcióval, NPC interakciókkal, valós idejű harccal és mobil tap-inputtal. Több JavaScript játékot is készítettem hobby projektként, beleértve a Space Dodge-ot, a Real-time Space Travel-t és a Bullseyes-t. Dolgoztam Phaser-rel játék prototípusok készítésében, és értem a game loop-okat, sprite animációt és interaktív állapotkezelést.

A Scolia Technologies-nél egy valós idejű sporteredmény-platformot építettem WebSocket-adatfolyamokkal — ugyanolyan alacsony késleltetésű, interaktív rendszer, amely a hangvezérelt gaminget működteti. Értem a reszponzív UI kihívásait élő adatterhelés alatt.

Claude Code és Codex power user vagyok, és kényelmesen mozgok AI-asszisztált fejlesztési munkafolyamatokban. Git, CI/CD pipeline-ok, SQL és NoSQL adatbázisok terén is tapasztalt vagyok.

Örömmel vinném a frontend szaktudásom és a játékfejlesztési szenvedélyem a Galactic Fleet-hez. Az a lehetőség, hogy hangvezérelt szórakoztató élményeket építhessek okos eszközökre, pontosan az a kreatív, technikailag kihívásos munka, amiben a legjobban teljesítek.
