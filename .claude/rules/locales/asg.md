# Asgardian (asg) — Style Consistency Rules

Covers `scripts/locales/asg.js`. Asgardian is a fictional language with an Old Norse /
archaic Norse-English character. No correct translation exists — consistency is the only standard.

---

## Core Character

- **Archaic Norse-adjacent, noble, dignified.** Like Old English or Old Norse rendered readable.
- Short, declarative. No complex subordinate clauses.
- A sense of honor and craftsmanship permeates the vocabulary.

## Pronouns and Verb Forms

| Concept | Asgardian form | Example usage |
|---|---|---|
| I (subject) | `ek` / `ég` | "Ek byggja…", "Ég em smiðr" |
| You | `þu` | "Hvat kýss þu?" |
| Is/am | `em` | "Ek em smiðr" |
| We | `vit` | rare in this CV |

Use `ek` and `ég` interchangeably but not within the same label — pick one per phrase.

## Style Rules

- Use `þ` for the "th" sound: `þu` (you), `þetta` (this) — consistent with existing labels
- Long compound nouns are natural: `"framhlið taknileiðtogi"` (Frontend Tech Lead)
- Avoid mixing modern English words mid-phrase except for proper nouns: `"React"`, `"TypeScript"`
- Titles and roles written in lowercase (Old Norse style): `"framhlið smiðr"` not `"Framhlið Smiðr"`

## Consistency Checks

- `ek` vs `ég`: same label must not switch between the two
- `smiðr` always used for developer role (not `forritari` which is more Icelandic-modern)
- `starfsferill` for the Work Experience section header — do not use alternatives
- `rað mik` for "hire me" — matches existing `"Rað mik!"`
- No English auxiliary verbs: not `"ek have built"` — use pure Asgardian constructions
