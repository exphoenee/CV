# Goa'uld (goa) — Style Consistency Rules

Covers `scripts/locales/goa.js`. Goa'uld is a fictional language from Stargate SG-1.
Commanding, imperious, self-aggrandizing — system lords speak as gods.

---

## Core Character

- **Pompous, commanding, self-important.** A Goa'uld does not request — they decree.
- Short to medium length phrases. Every statement implies superiority.
- Mix of commands (`Kree!`) and formal declarations.

| `Jaffa`    | Warrior / Servant           | Used for the "reader" — slight condescension |
| `Shol'va`  | Traitor (used ironically)   | For competitor roles (PM, Scrum)             |
| `Hok'tar`  | Advanced human / enhanced   | Used for developer roles                     |

| `Chel nok` | Hail and acknowledge        | Greeting/salute                              |

## Style Rules

- Start commands with `Kree!` where emphasis is needed: `"Kree! Tal mak. Nok:"`
- Apostrophes in Goa'uld words are intentional: `Hok'tar`, `Lo'taur`, `Tau'ri`, `Kel'shah`
- Tech proper names remain unchanged: `React`, `TypeScript`, `JSON`, `Svelte`
- Goa'uld does not use "please" — commands are direct
- Section headers are declarative, not inviting

## Consistency Checks

- `Lo'taur! Kree!` for "hire me" — the established phrase
- `Joma i:` for "CV of:" — the established opener
- `Joma i kel'shah` for Work Experience section
- `Hok'tar noc` for Education
- `Tau'ri lam` for Languages
- `Joma lam` for Programming Languages
- `Kree!` as opening attention-getter — must not be replaced
- Apostrophes preserved in `Hok'tar`, `Lo'taur`, `Tau'ri`, `Kel'shah`, `Ha'tak`
- No mixing of real-world formal registers (no "Please", "Thank you") — always commanding tone
